# Сборка на Windows

Требуется Windows 11 x64 и PowerShell. Visual Studio не обязательна.

## Обычная сборка

Из корня репозитория выполните:

```powershell
.\build.ps1
```

При необходимости скрипт скачает официальный переносимый .NET SDK **8.0.428**, проверит SHA-512 и сохранит его внутри `work/tools`. NuGet загрузит библиотеки WinUI 3 и средства Windows SDK. Интернет нужен при первой загрузке инструментов и пакетов.

Если нужный SDK уже установлен:

```powershell
.\build.ps1 -DotNetPath (Get-Command dotnet).Source
```

Результат: `dist/AirMirror-1.5.2-WinUI3.exe` и `dist/SHA256SUMS.txt`. Готовому EXE отдельная установка .NET или Windows App SDK не нужна.

Пакеты фиксируются файлом `packages.lock.json`, SDK — `global.json`. Перед компиляцией проверяется SHA-256 встроенного приёмника. Для сборки без публикации используйте `-BuildOnly`.

## Изменения нативного приёмника

Для обычной сборки используется проверенный `native/engine.zip`. Чтобы пересобрать его с адаптерами:

```powershell
.\build.ps1 -RebuildNative
```

Скрипты получают исходный релиз AirPlay-Windows v0.4.1, проверяют его SHA-256, применяют проверяемые изменения PE, собирают адаптеры Zig 0.14.1 и обновляют `native/engine.zip` вместе с контрольной суммой. Нужные инструменты остаются в `work/tools`. Обновление архива и его SHA-256 следует включать в один коммит.

Для пересборки нужны встроенные в Windows 11 `tar.exe` и компилятор .NET Framework 4.x (`%WINDIR%/Microsoft.NET/Framework64/v4.0.30319/csc.exe`). Visual Studio и установленный Visual C++ Redistributable не требуются. Нативный архив собирается в новом каталоге `work/native-build-*`, поэтому старые файлы предыдущей сборки в него не попадают.

Библиотеки Visual C++ 14.44.35211 берутся из официального архива Microsoft размером около 3,2 МБ; точный URL, SHA-256 и каталог происхождения записаны в `native/vc-runtime.json`. Сборка проверяет полный необходимый набор DLL и включает исходную лицензию Microsoft. Системные DLL компьютера сборки не копируются.

Все загрузки сначала сохраняются во временный файл и проверяются по контрольной сумме. Повреждённый кэш автоматически скачивается заново; прерванная загрузка не становится готовым архивом. Автономные проверки этого поведения и комплектности Visual C++ запускаются командой `./scripts/Test-BuildScripts.ps1`, без сети и запуска приложения.

Полные исходники оригинального приёмника и его собственные инструкции CMake/vcpkg находятся в `native/upstream`. Описание изменений: `native/THIRD_PARTY.md`.

## Проверка на реальном рабочем столе Windows

Закройте работающую AirMirror перед запуском проверок:

```powershell
.\tests\Run-Integration.ps1 -Executable .\dist\AirMirror-1.5.2-WinUI3.exe -DataDirectory .\work\self-test
```

Отчёт сохраняется в `work/self-test/self-test.txt`. Проверка включает запуск приёмника, обнаружение AirPlay, реальное встраивание окна, вертикальную/горизонтальную геометрию, полный экран, трей, очередь кадров, локальный RTSP и синтетический видеовывод.

Параметр `-Recovery` дополнительно намеренно завершает дочерний приёмник и проверяет его восстановление с прежним идентификатором. Тесты нельзя запускать во время пользовательской трансляции. Скрипт сохраняет и восстанавливает файлы параметров в `%APPDATA%`: сам `AIRMIRROR_DATA_DIR` перенаправляет только кэш и журналы. Для автоматических GUI-проверок предпочтителен отдельный профиль Windows.

Автономные регрессии и команды сетевых проверок описаны в [tests/README.md](../tests/README.md). GitHub Actions запускает проверки движка и скриптов, собирает EXE и публикует артефакт сборки. Проверки интерфейса и настоящего iPhone требуют интерактивного рабочего стола и отдельно в CI не заявляются.
